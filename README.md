# Obeya

Obeya is an open-source, self-hosted "software factory": it runs multiple specialized AI agents,
on its own agent harness, against configurable, kanban-shaped workflows, with
GitHub-Actions-grade observability into what each agent did and why.

> **Status:** early development (milestone M1). Nothing here is usable yet.

## Repository layout

| Path | What it is |
| --- | --- |
| `obeya-model/` | Workflow and card-template model: YAML parse, validation, JSON Schema compile |
| `obeya-expr/` | `${{ }}` expression evaluator, shared by the registry and the runner |
| `obeya-api-client/` | Client for the runner API and the job socket, shared by the runner and the CLI |
| `obeya-harness/` | The Obeya agent harness: loop, sessions, tools, compaction, provider clients |
| `obeya-server/` | Spring Boot control plane: REST, runner API, scheduler, services |
| `obeya-runner/` | Runner host process: work loop, podman, built-in actions; hosts the harness |
| `obeya-cli/` | The `obeya` CLI (picocli), built as a GraalVM CE native image |
| `tools/stub-model/` | Scripted Anthropic Messages model endpoint for CI and spikes |
| `web/` | Vue 3 + TypeScript + Vite SPA |
| `images/` | Containerfile for the job base image |
| `packaging/rpm/` | RPM spec and `obeya-setup` |
| `evals/` | Coder task suite for the harness quality bar |
| `e2e/` | End-to-end suite against the `xpertss-test` GitHub org |

## Building

Requires JDK 21, Maven 3.9+, and Node 24 (for the projen toolchain).

```bash
npm ci          # once, installs the pinned projen toolchain
mvn -B verify   # compile, unit tests, integration tests
```

`npx projen build` regenerates the build files and then runs `mvn -B verify`.

## Build files are generated

The poms, `.gitignore`, `.editorconfig`, `LICENSE`, and `.github/workflows/` are generated by
[projen](https://projen.io) from [`.projenrc.ts`](.projenrc.ts), using the project types in
[`@xpertss/projen-types`](https://github.com/xpertss/projen). Don't edit them by hand: change
`.projenrc.ts` and run `npx projen`. CI fails a pull request whose generated files don't match.
